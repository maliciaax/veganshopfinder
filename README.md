# Vegan Shop Finder

Site web permettant de recenser et consulter des magasins.

[🌐 Voir le projet en ligne](https://veganshopfinder.gyptis.org/appliVegan/index.php)
<br>

### 🛠️ Technologies
- PHP
- MySQL
- HTML
- CSS
- Leaflet
<br>
### 📋 Présentation
Ce projet a été réalisé dans le cadre de ma formation en développement web.
L'objectif était de concevoir un site permettant de consulter des magasins à partir de données stockées en base de données.
<br>

### 💻 Compétences mises en pratique
- Développement en PHP
- Utilisation d'une base de données MySQL
- Création d'interfaces HTML/CSS
- Gestion et affichage de données
- Organisation d'une application web
